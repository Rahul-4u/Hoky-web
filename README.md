# Hockey Website

Welcome to the **Hockey Website**! This project is designed to provide a dynamic and engaging platform for hockey enthusiasts.

## 🚀 Features
- Fully responsive and user-friendly UI
- Interactive homepage with match updates
- Players' profiles and team details
- Live score updates and news section
- Gallery with high-quality images
- Contact page for inquiries and feedback

## 🛠 Technologies Used
- **HTML** – Structuring the content
- **CSS & Tailwind CSS** – Styling and layout
- **JavaScript** – Adding interactivity
- **React.js** – For dynamic UI components (if applicable)
- **Node.js & Express.js** – Backend support (if applicable)
- **MongoDB** – Database for storing player and match data (if applicable)

## 📌 How to Run the Project
1. Clone the repository:
   ```sh
   git clone https://github.com/your-username/hockey-website.git
   ```
2. Navigate to the project directory:
   ```sh
   cd hockey-website
   ```
3. Open `index.html` in your browser, or if using React:
   ```sh
   npm install
   npm start
   ```
